MOZAIK TO DECORATIVE DEFRUSTRATOR
Left Coast Cabinets

1. Double-click Mozaik to Decorative Defrustrator.exe.
2. Click Open PDF and choose a Mozaik door / drawer-box size report.
3. Review the two tabs. Click a row and use Change type, or double-click
   to edit its sizes and other options. The copy window can edit rows too.
4. Leave Export section on All sections for the combined tables,
   or select an individual section to order a particular style.
5. Click Copy for Decorative to see the supplier's rows and columns.
   Choose Doors & standard fronts, Fronts under 7 inches, or Drawer boxes
   & trays. Click Copy all
   rows, then paste into Decorative's matching Excel-data input box.
   Copy each table separately. For fronts under 7 inches, configure the
   narrower top and bottom rails in Decorative before adding that group.
   Save CSVs writes a separate file for each nonempty table.
6. Click Hardware email to review the whole PDF's hardware. Enter part
   numbers and quantities for any additional hinges, then create and
   copy the email body. Leave additional quantities blank or 0 to skip.
7. Click Clear data to empty the review and start a new conversion.
   If you have unsaved edits, the app offers to save the editable order.
8. Click Save order (Ctrl+S) to keep your work in a .mddorder file.
   Click Open order to resume it later. Use File > Save order as to keep
   a separate copy. The original PDF is not needed to reopen the order.

UPDATE 1.21
- Light blue highlights customized rows in the main app and Copy for
  Decorative. It compares current values with the imported row and standard
  bore defaults, including quantity-1 rows created when splitting doors.
  The row editor highlights the individual values that differ.
- Saving an order keeps these highlights. Undo/Redo updates them, and
  returning a value to its original setting removes its highlight.
- Top and bottom bores now have a Mozaik offset input next to the final
  position. Enter 0 for the standard 4 inches; enter 3 for 4 + 3 = 7 inches.
  A negative offset moves closer to the edge: -1/2 gives 3 1/2 inches.
  Top is measured from the top; bottom is measured from the bottom.
- You can also edit the final position directly; its offset updates to
  match. The illustration and live equations show how the offset works.
  Blank clears a position; Reset bore positions restores the defaults.
- Fractions stay exact in saved orders, Decorative copies, and CSVs.
  Invalid offsets or positions outside the door cannot be applied.
  Center-bore reference conversion, hinge-side confirmations, and
  Undo/Redo continue to work. The window title shows v1.21.

UPDATE 1.17
- Edit a door's top, center, or bottom bore position, then Apply changes.
  If the row has more than one door, the app asks whether to duplicate
  the custom bore position for the other door(s).
- Yes applies all three positions to every door and creates separate
  quantity-1 rows. A pair becomes one L row and one R row. For more than
  two doors, confirm the number of left- and right-hinging doors.
- No applies the custom positions to one door, asks its hinge side,
  and keeps the remaining doors together with their original settings.
- For a quantity-1 row, confirm Left or Right hinging. The choice stays
  on that line item and carries through to Decorative copies and CSVs.
- Cancel returns to the editor without applying anything. Ctrl+Z undoes
  the whole split and restores the original row; Ctrl+Y repeats it.
- These prompts apply to hinged doors, including Glass. Drawer fronts
  and Applied Doors keep their existing rules. Total quantity is preserved.
- The window title shows v1.17.

This file contains part numbers and units only; no job quantities or PDFs.

DEFAULTS
- Drawer fronts: 5-Piece Drawer Front; Bore None; Location none;
  Center Bore no; top, center, and bottom positions blank by default.
- Doors: Bore A, Location L; explicitly named Susan doors use Susan.
- Explicit glass door labels: Glass.
- Center bore: Yes only when door height is greater than 36 inches.
  The center position is exactly half the door height.
- Door top and bottom bore positions: 4 inches each.
- Trays: Scoop A. Drawer boxes: Scoop blank.
- Dimensions: exact fractional inches. No overlay,
  opening-size adjustment, or rounding is applied.
- Hardware: available in Hardware email; excluded from the supplier CSVs.

REVIEW
The sample's Door Size labels do not reveal glass or lazy Susan status.
If Mozaik does not label these explicitly, choose Glass or Location Susan
manually after checking the cabinet plan. A row represents its entire
quantity. Ordinary edits apply to every piece in that row. Custom door
bore edits ask whether to apply them to one door or every door, and split
the row as described in Update 1.17 above.

The PDF may contain several styles. Style, material, species, and finish
are not in the supplier CSV columns. Use the Export section selector to
save separate files when those styles require separate supplier orders.
The two combined sample CSVs contain all supplied styles.

Columns match the provided Anytime Online workbook and screenshots,
including the workbook's trailing space in the Bore header. The live
Decorative Specialties paste screen has not been tested. Check the supplier's
preview before submitting an order.

The app checks extracted quantities against each PDF section total.
Unrecognized pages, missing totals, unreadable rows, or scanned pages
block export. Use text-based Mozaik reports with the same ruled Door Sizes
and Dwr Box/Tray Sizes tables as the supplied example.

Double-click a row to change type, location (L / R / Susan), quantity,
dimensions, French Lite configuration, scoop, or bore positions. Bore
positions start with automatic defaults and can be edited or reset.
You can exclude an entire row from export.
Rules & checks shows the original PDF total checks. Edits change the
exported quantities, and are not saved back into the source PDF.

New CSV exports never overwrite an existing file; a numbered filename
is used. Save order keeps applied edits in an editable .mddorder file so
you can reopen and continue later. Save CSVs creates supplier tables.
